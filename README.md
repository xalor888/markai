# MarkAI — 智能书签管家 Agent

> 赋予 AI「最高管理权」的浏览器书签管理器。**自由对话的 Agent**：聊天即可让它整理、扫描、清理你的收藏夹，所有操作透明可见，删除永远需要你确认。

基于 **WXT + React 19 + TypeScript + Tailwind CSS v4 + shadcn/ui + Zustand** 构建，兼容 Chrome / Edge（Manifest V3）。

---

## 核心能力

| 能力 | 说明 |
| --- | --- |
| **自由对话 Agent + 多会话管理** | 侧边栏/完整页内直接聊天：「帮我把 GitHub 相关书签整理到一个文件夹」「扫一下有没有死链」；**支持多会话**：新建 / 切换 / 双击重命名 / 删除（会话面板），首条消息自动生成标题 |
| **30 个书签工具** | 增 / 删 / 改 / 移动（单个+批量）/ 复制 / 重命名 / 搜索（可限条数）/ 死链实测（HEAD 请求，每批 50）/ **URL 分类（classify_urls：root/page/sub/deep，主页面筛选任务专用）** / **批量新建（create_bookmarks，一次 50 条）** / 统计 / **查重（find_duplicates）** / **排序（sort_folder）** / **删除全部（delete_all_bookmarks）** / **查看文件夹结构（get_folder_content）** / **导出清单（export_bookmarks：扁平化含收藏日期与可选 id，offset/maxItems 分页，大清单分批取完）** / **合并文件夹（merge_folders）** / **批量打开（open_bookmarks）** / **空文件夹清单（list_empty_folders）** / 路径定位（list_bookmarks 支持 folderPath + 分页），全部在浏览器后台闭环执行（读类工具并行、写类串行）；**大库专用工具：check_urls_bulk（一次检测上万条链接，并发 20 + 单条超时 + 实时进度 + 摘要回传）、auto_categorize（一次调用按域名聚类分类整个文件夹，移动并发 10 路）、cleanup_sweep（一键清理：按收藏年份+页面类型筛选存活检测批量删除提议，自动适配「无需确认」模式）** |
| **删除安全闸门** | 默认：Agent 只能提交「删除提议」→ 聊天内卡片勾选或顶部「待删 N 项」汇总清单 → 你确认后才会真正删除（`removeTree`）；**可在设置页切换为「无需确认」模式**（提议自动执行）；「删除全部」默认同样需确认，根文件夹永远不可删；每条提议可**在树中定位**查看位置；已执行/已放弃的提议不会被后续工具调用重新提交（终态保护） |
| **流式输出 + 工具调用循环** | SSE 流式回复（16ms 批量渲染 + 消息/工具块 memo 优化），**工具调用轮数无上限**（死循环检测 + 连续失败保护兜底），工具执行状态实时可视化；**AI 回复完整 Markdown 渲染**（GFM：表格/任务列表/删除线/代码块带复制按钮/链接新标签页打开）；**失败自动重连最多 5 次**（网络/5xx/429 指数退避，已输出不重试）；**对话可导出为 Markdown 文件（含工具结果）**；**上下文按 token 预算管理（窗口 × 阈值 − 固定开销，压缩保持完整轮次边界，防 API 400）+ 可选自动压缩早期消息** |
| **原生右键集成** | 浏览器书签上右键 → 「让 MarkAI 整理此文件夹 / 分析此书签」→ 自动打开侧边栏并注入指令 |
| **原生右键菜单** | 打开 / 新标签页（后台）/ 新窗口 / 复制网址 / **复制为 Markdown（含文件夹嵌套列表）** / **复制路径 / 所在路径** / **编辑网址** / 打开全部（**新标签页 / 新窗口 / 标签页组**，文件夹）→ 一键直达 |
| **三栏工作区** | 侧边栏（Arc 风格紧凑三栏 + 抽屉动画）+ 完整页（三分栏 IDE）双形态；**Agent 面板宽度可拖拽调整**（200~640px，记住你的设置） |

## 快速开始

环境要求：**Node.js ≥ 22**

```bash
npm install # 安装依赖
npm run dev # 开发模式：自动打开 Chrome 并加载扩展
```

生产构建 / 打包：

```bash
npm run build # 构建到 .output/chrome-mv3
npm run zip # 生成可分发 zip
```

> 若 `npm run dev` 未自动打开浏览器，手动到 `chrome://extensions` → 开发者模式 → 加载已解压的扩展程序 → 选择 `.output/chrome-mv3` 目录。

## AI 服务配置

打开 **设置页**（工作区右上角齿轮 / 弹出窗「AI 设置」）：

1. **服务商**：OpenAI / DeepSeek / Moonshot Kimi / Ollama（本地）/ 自定义（任意 OpenAI 兼容端点）
2. **Base URL**：选择预设后自动填充，也可改填代理地址或本地 Ollama（`http://localhost:11434/v1`）
3. **API Key**：仅存于浏览器本地 `chrome.storage.local`，请求由后台直接发给所选服务商，不经过任何中间服务器
4. **模型**：预设模型的快捷下拉 + 自由输入；点 **「获取模型列表」** 从服务商实时拉取（`GET /models`，兼容 OpenAI 与 Ollama 格式）
5. 点「测试连接」验证配置
6. **删除与上下文**：删除确认模式（始终确认 / 无需确认）、**模型上下文长度**（手动填写或从服务商 `context_window` 自动带入）、压缩阈值与自动压缩开关（达到阈值自动摘要早期消息，压缩保持完整轮次边界）

> 建议：国内网络优先 DeepSeek（`deepseek-v4-flash`）或 Moonshot Kimi；本地无成本体验用 Ollama。

## 使用示例

- 右键任意书签 **让 MarkAI 分析此书签**（检测死链、给出整理建议）
- 右键书签文件夹 **让 MarkAI 整理此文件夹**（自动创建子分类并归类移动）
- 中栏勾选多个书签 **让 MarkAI 整理**（批量归类；Ctrl/Cmd+点击切换选择，Shift+点击或 Shift+方向键范围多选，中键/新标签页打开）
- 聊天输入「**智能扫描清理**」→ Agent 实测链接存活 → 生成删除提议卡片 → 勾选确认执行
- 聊天输入「**只保留主页面**」类任务 → Agent 分页导出（含收藏日期）→ `classify_urls` 分类主/子页面 → `check_urls` 实测存活 → 删除提议等你确认
- 顶部「**待删 N 项**」→ 汇总本次会话所有删除提议，可全选一键清理
- 搜索结果右键 **在树中显示**（展开祖先链并滚动定位）
- 会话管理：聊天头部「会话」按钮 → 新建 / 搜索 / 切换 / 双击重命名 / 删除
- 拖拽书签到树中文件夹或中栏列表 = 移动；**按住 Ctrl 拖拽 = 复制**（文件夹深拷贝）
- 右键书签 → **编辑网址**（URL 校验，自动补协议）；→ **复制为 Markdown**（写文档）；文件夹可复制为嵌套 Markdown 列表
- 右键文件夹 在新标签页 / **新窗口** / **标签页组** 中打开全部（去重，最多 25 个）
- 回复出错或想换个说法 悬停最后一条回复点 **↻ 重新生成**（重试保留文件夹上下文）
- 聊天输入会**自动附带当前文件夹上下文**——「把这里的书签整理一下」无需手动指定；消息上方显示**上下文标签**（可点击定位到树）
- 聊天面板头部点击 **上下文文件夹** 可在树中定位；点击 **模型名** 直达设置；**导出对话**为 Markdown 备份
- 完整页按 `Ctrl+K` 聚焦搜索框；树/列表内按 **`/`** 也可聚焦；搜索框内 **Enter** 直接打开第一条匹配；列表 **Ctrl+C** 复制选中/高亮网址；`Ctrl+Shift+M` 随时打开侧边栏

## 说明

- 图标为程序化生成的 MarkAI 品牌图标（Indigo 实底 + 白色书签，SDF 超采样抗锯齿，16px 依然可辨），可用 `node scripts/generate-icons.mjs` 重新生成；如需自绘替换 `public/icon/*.png`（16/32/48/96/128）
- `check_urls` 会向所选书签站点发起 HEAD 请求（8s 超时，并发池 5、每批 50），用于实测死链
- 聊天历史（多会话）、待删清单持久化在 `chrome.storage.local`，可在设置页一键清空（墓碑机制防其他窗口复活）
- popup 的「去处理」会直达完整页的待删除清单（`page.html#deletions`）
