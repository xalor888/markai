# 隐私说明（MarkAI）

MarkAI 是一个**本地优先**的浏览器扩展：它没有后端服务，开发者不运营任何接收你数据的服务器。
这份文档写的是**实际会发生什么**（逐条与代码核对过），不是模板话术。

## 1. 留在你机器上的数据

全部存在扩展自己的 `chrome.storage.local`（按扩展隔离，其他扩展读不到）：

| 键 | 内容 |
| --- | --- |
| `markai.config` | AI 服务商配置：Base URL、模型名、**API Key**、上下文长度、删除确认模式 |
| `markai.ai` | 聊天记录（多会话）、待删除提议清单 |
| `markai.undo` | 操作日志（撤销点），含被删书签的子树快照 |
| `markai.ui` / `markai.theme` | 界面状态与主题 |
| `markai.seed` | 右键菜单派发指令的**瞬时**中转，消费后立即删除 |

**API Key 是明文存储**的（`chrome.storage.local` 不是加密存储）。能访问你这台机器上该浏览器
profile 的人或恶意软件可以读到它——请像对待其他本地凭据一样对待它。扩展运行时不会把它写到别处。

**没有遥测**：没有埋点、没有统计上报、没有账号体系、没有崩溃上报。扩展不检查更新，
也不在你不知情时联系任何服务器。

## 2. 什么会离开你的机器

### 2.1 发往你选择的 AI 服务商

这是唯一由你主动触发的对外通信。请求直接发到你配置的 `Base URL`
（OpenAI / DeepSeek / Moonshot / 本地 Ollama / 任意 OpenAI 兼容端点），**不经过任何中间服务器**。

会发出去的内容：

- 你的**对话文本**（以及为了上下文而附带的历史消息）；
- **工具执行结果**——这是关键：当你让 Agent 整理/扫描书签时，读取到的**书签标题与网址**
  会作为工具结果发给模型，模型才能据此决策；
- 当前查看的文件夹上下文。

也就是说：**用云端模型时，你让它看的书签内容会到那家服务商那里**。若不想这样，用本地 Ollama
（`http://localhost:11434/v1`）即可全程不出本机。

### 2.2 发往你书签里的站点

「死链检测」类工具（`check_urls` / `check_urls_bulk` / `cleanup_sweep` 的实测环节）
会**直接向书签指向的 URL 发 HEAD 请求**（对方返回 405/501 时降级为 GET），8 秒超时。

- **不携带凭据/Cookie**（`fetch` 默认 `same-origin`，跨站不发送），所以站点不会因此把你的登录态关联起来；
- 但这些站点会看到"有请求来过"，且请求来自你的 IP —— 检测的是你已经收藏的站点，
  不过它仍然暴露了「你在何时检查过它」。

不想让扩展联系这些站点，就不要使用检测类工具（它们不是必需功能）。

## 3. 不做什么

- 不上传你的书签库到开发者或第三方（除了上面 2.1 里你选的模型服务商）；
- 不读你的浏览历史、不注入网页脚本、不修改任何网站内容
  （权限清单见 [permissions.md](./permissions.md)：只有 `bookmarks` / `storage` / `tabs` /
  `tabGroups` / `contextMenus` / `sidePanel`，没有 `history`、没有 content script）；
- 不因为"改进产品"而收集任何使用数据。

## 4. 如何清除

- **聊天记录 / 待删清单 / 撤销记录**：设置页 →「清空本地数据」会一并删除
  （撤销记录里含被删书签的子树快照，所以同属需要能清掉的本地数据）；不影响书签本身；
- **全部**：在 `chrome://extensions` 卸载扩展，`chrome.storage.local` 会被浏览器一并删除；
- 书签本身由你与浏览器管理，扩展删除书签的操作都可撤销（见 README 的「操作可撤销」）。

## 5. 这份文档的边界

- 面向 Chrome / Edge（Manifest V3）。**Firefox 未验证**，因此不发布 Firefox 产物（见 release.md）。
- 扩展**没有**做端到端加密：发给服务商的内容按该服务商的策略处理，请自行阅读其条款。
- 若你使用第三方代理地址作为 Base URL，那份数据的经手方就是该代理——这是你的配置选择。
