## 二、删掉的东西（不是隐藏）

**补整理整条链路**：`organize:sweep` 三个消息、`startOrganizeSweep` / `runOrganizeSweep`、
`sweepRunning` / `sweepSnapshot`、UI 的进度条 / ETA / 取消 / 「还有 N 条散落」、
`collectLooseBookmarks*` / `moveBookmarkInto` / `estimateRemainingMs` / `formatRemaining`。

**为什么删而不是改**：它的形态（点按钮 → 后台固定算法 → 批量搬存量）与"对话驱动、每步可见"
是两套东西。给它加 dryRun 只是套壳。

**按域名建文件夹一并删掉**，包括新收藏的兜底：系统提示里加了硬规则
「不要按域名新建文件夹；认不出就留在原地并说明」。
