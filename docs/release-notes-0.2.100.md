# v0.2.100 — Shift+Enter 承诺"不抢当前页面"，验过了

## 缺口

快捷键速查表写着：

> Shift+Enter：在后台新标签页打开

e2e 从没验过。

用户按它是为了**不离开当前页面**——如果实际把当前标签页抢走了，
他正在看的整理结果就被换掉了，**这个承诺就成了反效果**。

## 验了什么

```
PASS  Shift+Enter 在新标签页打开，且不抢走当前页面
```

判据三条同时成立：

1. 多了一个标签页，URL 是目标书签
2. 那个标签页是 **`active: false`**
3. 当前标签页没有被换掉

## 过程中的一个坑

第一版跑出来 `bgActive: null`——根本没打开目标书签。

调试发现高亮行停在「Beta 指南」：这一段跑在前面一堆导航之后，
**列表停在别的文件夹**，我刚建的书签压根不在列表里，方向键走 12 步也到不了。

补一步：先点树里的「书签栏」把列表切过去。

> 又一个「红的时候先怀疑自己的判据」——产品是对的，是我的用例没站在对的文件夹里。

## 验证

**证伪**：把 `openUrl(n.url, { active: !e.shiftKey })` 改成永远 `active: true`
（Shift 也抢焦点）→ 该条转红。
