# v0.2.106 — 「声明了但没实现」的工具，从此有测试守着

## 为什么做这个

AI 的工具有两边：

- `TOOL_DEFINITIONS` —— **模型看得见的**（告诉它"你能做什么"）
- `TOOL_MAP` —— **真正能执行的**

两边漂移是最难自查的一类：**声明了但没实现**时，模型会理直气壮地调用，
然后执行器抛 `未知工具：xxx`——你在聊天里看到一次莫名报错，
而单测里没有任何一条会红（每条工具都是单独测自己的 handler）。

反向也烂：**实现了却没声明**的工具，模型根本不知道它存在，等于白写。

## 做了什么

从 `tools.ts` 导出 `IMPLEMENTED_TOOL_NAMES`，加一条契约测试：

```
声明的每个工具都必须有实现     （差集为空）
实现了的每个工具都必须声明     （反向差集也为空）
```

当前 34 个工具，两边一致。

## 验证

**证伪**：从 `TOOL_MAP` 删掉 `forget_memory` 的处理器：

```
AssertionError: 声明了但没有实现的工具：["forget_memory"]
```

## 顺带：我自己错了一次

中途用 `sed -n '1957,1990p'` 抽工具名，范围短了一行，把 `forget_memory`
（在 1991 行）漏掉，一度以为真有个「声明了没实现」的缺陷。

重抽后两边一致——**又是「先怀疑自己的判据」**。
