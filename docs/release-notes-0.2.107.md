# v0.2.107 — 别让 `create_bookmark` 这种裸名漏进中文界面

## 缺口

聊天里的工具 chip 是这样渲染的：

```tsx
{meta?.label ?? record.name}
```

**没有标签时就回退到裸工具名。**

于是任何一个忘了在 `TOOL_META` 里登记的工具，都会在全中文的界面里显示成
`create_bookmark`、`forget_memory` 这种英文蛇形——看起来像没做完。

而每条工具都是单独测自己的 handler，**没有一条会为「忘了加标签」而红**。

## 做了什么

一条契约测试：

```
每个已实现的工具都必须有中文标签
标签表里多出来的键也是腐烂（工具已不存在）——反向也查
```

34 个工具，两边一致。

## 验证

**证伪**：删掉 `forget_memory` 的标签：

```

```
