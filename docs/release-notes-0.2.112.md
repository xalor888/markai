# v0.2.112 — 想单独放开第 4 个站点？没有入口

## 缺陷

整理记录的「站点免打扰」名单里，每个站点旁边有个 `×`，点它单独恢复。

但渲染是：

```tsx
{optouts.slice(0, 3).map((o) => ( /* 可点的 × */ ))}
{optouts.length > 3 && <span>等 {optouts.length} 个站点</span>}
<button>全部恢复</button>
```

**只渲染前 3 个。** 第 4 个起只剩「全部恢复」。

而紧挨着的注释写着：

> 每个站点单独可恢复：只想放开一个站点时，不该被迫「全部恢复」

**那句话只对前 3 个成立。**

撤销过 5 个站点的用户想单独放开第 4 个——没有任何入口，只能全部恢复
（把另外 4 个一起放开，正是他不想的）。

## 修法

加展开开关：默认仍只显示前 3 个（不占地方），`等 N 个站点` 变成可点的展开按钮，
展开后全部逐个可恢复。

## 验证

e2e 新增 **6 项**（种 5 个站点 → 未展开只 3 个 → 有展开入口 → 展开后 5 个全可点
→ 单独恢复第 4 个后它消失、其余还在 → **存储里也真的少一条**，不是界面假装）。

**证伪**：把 `showAllOptouts ? optouts : optouts.slice(0, 3)` 改回 `optouts.slice(0, 3)` →

```
FAIL 7.1 展开后 5 个站点都可单独恢复 · ["oo5.test ×","oo4.test ×","oo3.test ×"]
```
