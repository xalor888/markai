# v0.2.118 — 「以下是你的全部规则」——其实只列了 30 条

## 缺陷

长期记忆注入系统提示时截到 30 条：

```ts
const active = memories.filter((m) => m.enabled).slice(0, maxItems);
```

但提示词的措辞是：

> **以下是已记录的用户长期偏好与规则。**……请严格遵守以下偏好与规则

一句「完整」的断言。

于是你有 40 条记忆时：**模型只看到 30 条，却以为那就是全部**，
剩下 10 条被默默忽略。

用户以为「我说过别再动这个站点」一直有效——其实那条记忆根本没进模型的视野。

这跟上一轮 `forget_memory` 只删一条却汇报「已忘掉」是**同一类假汇报**：
只给/做了一部分，却用完整的口吻说话。

## 修法

超出注入上限时，把话说全：

```
（注意：另有 11 条已启用的记忆因单次注入上限未在此列出。
当用户的指令可能与未列出的记忆相关时，请调用 recall_memories 查询，
不要假设上面就是全部。）
```

- 说清**还有几条**
- 给出**补救动作**（`recall_memories`）
- 直接点破「**不要假设上面就是全部**」

正好等于上限时不输出这句——不制造噪音。停用的记忆不计入「未列出」（它们本来就不该生效）。

## 验证

```
PASS  记忆注入超上限时说清"还有未列出的"，不冒充完整清单
```

四层都验：正好 30 条无提示 / 41 条时报「另有 11 条」/ 提示 `recall_memories`
与「不要假设上面就是全部」/ 停用不计入。

**证伪**：把 `truncationNote` 清空 →

```
必须说清还有几条没列出
```
