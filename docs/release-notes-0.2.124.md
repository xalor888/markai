# v0.2.124 — 「我前面说过别动那个文件夹」

## 缺陷

`selectHistory` 按 token 预算挑历史消息。`autoCompress` **默认关闭**。

关闭时，超预算的早期消息被**直接丢掉**，然后静默返回：

```ts
if (autoCompress && selected.length < history.length) {
  // …压缩成摘要…
}
return selected;   // ← 没开压缩就从这儿出去了，什么都不说
```

于是长对话里：

- 模型只看到最近几条，**它自己不知道还有更早的**
- 你那边的症状是「**我前面说过别动那个文件夹，你怎么还搬**」
- 而模型并不是不听——**那条消息根本没进它的上下文**

不说清楚，模型只会基于不完整信息**自信地行动**，你以为它忘了你的话。

设置页确实有一句「关闭（长会话可能超出模型窗口）」，但它在设置页，不在症状出现的地方。

## 修法

没开压缩且发生截断时，往上下文里塞一条系统说明：

```
【系统提示】本次请求因上下文窗口限制，只包含了最近 N 条消息，
更早的 M 条消息未包含在内。
如果用户引用了更早的对话内容（例如"我之前说过…"），
请如实说明你看不到那段对话，不要猜测其内容，也不要假装记得。
```

模型于是知道有缺失：被问到早期内容时**如实说「我看不到」**，而不是猜或者硬答。

开了 `autoCompress` 时不出现这条——摘要已经在承担同一件事。

## 验证

```
PASS 历史被截断时明确告知模型有缺失（不让他自信地基于半边信息行动）
```

20 条 × 2000 字符的历史 + 4000 token 窗口，必然截断。验四条：保留几条、丢几条、
要求别猜；反向验「开了压缩时不出这条、而是出摘要」。

