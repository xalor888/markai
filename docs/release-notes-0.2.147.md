# v0.2.147 — 取消后提示语说清「这一轮动没动书签」

## 缺陷

用户点了「停止」后，界面只显示「已停止生成」。

这会导致两种混淆：

- **纯读任务被取消**（如搜索/统计）→ 什么都没改，重来即可，但用户可能去点撤销白折腾
- **批量移动跑到一半** → 已经移走了若干条，撤销点里也有，不去撤销就会以为「停了＝没动」

之前的修复（0.2.145/0.146）把取消的改动计入了 mutations，也标了「已中断」——但在消息体里没告诉用户，他看不到自己做的这一步到底改了啥。

## 修法

新增 `cancelNote(blocks: ChatBlock[])` 纯函数：

```ts
export function cancelNote(blocks: ChatBlock[]): string {
  const { mutations } = retrySafety(blocks);
  if (mutations === 0) return '\n（已停止生成）';
  return `\n（已停止生成；这一轮已执行 ${mutations} 个改动，要退回请点「撤销」。）`;
}
```

在 `chat:cancelled` 分支调用，动态拼接进消息末尾。
