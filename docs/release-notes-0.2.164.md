# v0.2.164 — 从工具到管家

单测 883 → 1038。这一版不是加功能，是**把"书签整理器"变成"人"**：
它会思考、会记得你、会主动说话，而且能看见自己在想什么。

## 一、思考内容可见（含思考强度）

模型的思考过程**单独成块**，不混进回复正文：

- 流式时自动展开（`正在思考…`），结束后收起为「思考过程 · N 字」，点开可读全文；
- 复制整条回复时**跳过思考**（用户要的是答案，不是草稿）；
- 历史消息里的思考一律折叠（不占屏幕）。

## 二、思考强度按模型能力动态给

档位不写死。能力来自 models.dev 的 `reasoning_options`：

| 模型能力 | 界面给什么 |
| --- | --- |
| `effort` 档位 | 分段控件（低 / 中 / 高 / 很高 / 最高） |
| 只有 `toggle` | 两档（默认开 / 关闭） |
| 会思考但不可调 | **不给控件**，只显示"自动" |
| 不支持思考 | **不给控件**，说明"不会发送思考参数" |

**给了控件就是承诺它会发出去**。所以措辞与实际行为逐条对齐：默认档（`auto`）不向请求体添加任何字段——原本能用的端点不会因为新增参数被打成 400。

## 三、模型目录从 models.dev 自动匹配

手写的模型清单必然过期（实测 `deepseek-chat` / `kimi-k2` 在上游已经查不到）。现在：

- 拉取 `models.dev/api.json`（公开静态 JSON），24 小时缓存；
- **断网退到内置快照**，并明确标注"可能过期"；
- 上下文预算用目录里的真实窗口：`gpt-5.6` 从 128K 修到 **1.05M**（此前少算 8 倍，压缩阈值提前触发）。

隐私影响：请求只带 GET 本身，不带对话、书签、API Key。详见 `docs/privacy.md` 的 2.3 节。

## 四、Agent 面板与设置页（界面上的一次大改）

Agent 面板不再用吉祥物占位——它现在是一个"能干活的面板"：

- 顶部只回答两件事：**是谁**（品牌头像 + 名称 + 状态点）与**能做什么**（撤销/记忆/会话/导出等动作）；
- 上下文文件夹与当前模型贴到输入框内部（它们描述的是这一轮的上下文，不该和动作按钮抢宽度）；
- 空态换成三张**可执行的动作卡**（整理此文件夹 / 智能扫描清理 / 汇总统计）+ 建议/习惯卡，
  每条都有明确的下一步，而不是一只不会说话的眼睛；
- 输入区改成卡片式：⌘K 命令面板、Enter 发送、文件夹上下文 chip 与删除策略都在框内外一行内说清；
- 移除宠物视觉与拖拽物理（眼睛/弹簧/甩抛那套代码与测试一并删掉）——界面清爽，
  "管家感"留给真正有用的习惯候选与主动建议。

设置页同样重做：固定侧栏（品牌 / 搜索 / 分区 / 主题）+ 独立滚动内容区，
**⌘K 字段级搜索**（中英文别名都能命中）、分区卡片、右对齐控件与整行开关；
思考强度支持目录外的自定义档位，并把"实际发送"的字段预览写在界面上。

## 五、管家感

- **习惯**：从你说过的话里提取候选（"工作那个文件夹别动"），**只当候选**——
  问一次「要我记住吗」、能拒绝、拒绝真的生效（30 天）。看不见的记忆等于黑箱。
- **主动建议**：观察 + 你确认过的习惯 → 一句具体可执行的话
  （「有 2 组重复链接。按你惯用的『按语言分类』，我可以一次合并掉」）。
  **绝不自动执行**：点「开始」只是把这句话发给 Agent，改书签仍走逐次确认。
- **个性化**：称呼 / 回答详略 / 主动程度，三个开关都真的影响行为（默认不改变任何行为）。

## 六、UI

- **玻璃层**：只用在浮层（Toast / 对话框 / 菜单 / 命令面板），`backdrop-filter` + 1px 描边 + 顶部高光；
  扩展页面无法模糊背后的网页，所以侧边栏容器刻意不用——放了只会糊到自己的纯色底。
- **对比度可执行**：测试从 `main.css` 解析真实 token，按半透明合成色算 WCAG 比值
  （最坏底层取最小），谁把 token 调坏，测试报出具体比值。
- **图标标尺**：12/14px 占图标量级的 93.9%，10px 图标已清零。
- **动效**：`prefers-reduced-motion` 通配兜底（用 0.01ms 而非 0，保证 `transitionend` 仍会触发）。

## 数据事实

- 包体 **1.09 MB**（0.2.163 是 1.06 MB；主要增量来自模型目录与界面/自定义档位逻辑）。
- 固定开销**一分没涨**：系统提示 1,203 tok / 工具定义 5,455 tok / 小计 6,658 tok，与五天前完全一致。
- 历史里的工具结果现在会**转写成摘要**再发给模型（此前 200 轮对话里有 66% 的内容模型根本看不到，
  导致"记不住刚查过什么"、反复重查）。

## 已知限制

- 思考内容不写进流式草稿（`stream-draft` 只存正文）：SW 被杀时会丢思考，正文不受影响。
