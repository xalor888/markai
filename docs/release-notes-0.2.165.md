# v0.2.165 — 个人书签管家

本次大改的收口版本。不是加一排按钮，而是把「书签管理器」拆成四个真正的工作面：
**看的（概览 / 时间线）**、**找的（搜索 / 命令面板）**、**干的（多选 / 体检 / 计划）**、**说的（Agent 面板）**。

## 一、概览：打开就知道库怎么样

- 时间段问候（只有你填了称呼才带名字，不编"主人"）；
- 四个指标：全部 / 今天新增 / 重复链接 / 空文件夹，全部可点击；外加最近 7 天逐日迷你趋势；
  每周首次打开有一次「本周回顾」（新增 / 整理 / 失败 / 重复与空文件夹变化）；
- 最近整理、管家建议、书签体检入口在同一页；
- 所有动作都变成给 Agent 的具体指令，概览本身**不写任何书签**。

## 二、搜索与命令面板

- 主搜索：250ms 防抖，结果按「文件夹 / 书签」分组；最近搜索 5 条（可清除）；
- `⌘K` 命令面板：空查询先给「最近使用 + 6 个常用动作 + 文件夹」；
  视图切换 / 体检 / 收藏当前页 / 切主题都能键盘直达；
- `?` 打开快捷键速查；`⌘1/2/3` 切概览 / 列表 / 时间线。

## 三、列表与选择

- 多选浮层在列表底部：整理 / 移动 / 删除 / 更多；窄屏图标化但都有可访问名称；
- 行内 hover 才出现「打开 / 在树中定位」，不抢单击打开；
- 时间线：今天 / 7 天 / 30 天 / 全部 + **按天 / 按域名** 两种分组；
  排序支持最新收藏 / 最早收藏 / **最近打开**（按 `dateLastUsed`）；按域名分组可一键打开全部；
- 拖拽保留插入线、边缘自动滚动、批量与跨根移动。

## 四、Agent 面板

- 会话侧栏：搜索 / 双击重命名 / 二次确认删除 / 新建，覆盖整个面板；
- 记忆中心：开关停用、分类与来源、删除、空态引导；
- 管家日报：今天整理 N 条 / 失败 N 条 / 可撤销 N 步，仅今天有整理时出现；
- 斜杠命令：`/整理` `/清理` `/记住` `/概括` `/找`，↑↓ 选择、Enter 填入、不自动发送；
- 工具卡 / 计划卡统一圆角与状态色，失败消息操作条常亮。

## 五、收藏建议

- popup 收藏当前页时给出「建议存到…」：同域名已有条数优先，其次整理日志的历史去向；
- 只建议不执行：点「存到这里」才使用该文件夹，默认按钮仍是书签栏；没有信号就不显示。

## 六、标签

- 本地 storage 的 `书签 id -> 标签` 多对多映射，不改 Chrome 书签结构；
- 每条最多 5 个标签、大小写不敏感去重；右键「标签…」或多选「更多 → 添加标签…」；
- 标签条只在有标签时出现，点击筛选全库；切文件夹或输入搜索自动退出；
  主搜索输入 `#标签` 也能直接筛选（复用同一套标签数据）；
- 标签条右侧可「管理」：重命名到已有名字即合并，删除为两步确认；
- 每个标签可选 6 色（默认/蓝/绿/琥珀/玫红/紫），只影响标签条与对话框，不写书签；
- 多选后可一次移除某个标签（保留其他标签），与添加对称；
- 书签行 hover / 聚焦时显示标签数（颜色取首个标签色），title 列出全部；点标签数即按该标签筛选；
- 标签支持 JSON 导出/导入：保留颜色，导入时跳过当前库里不存在的书签 id；
- 删除书签后自动清理孤儿标签 id。

## 七、体检与修复

- 五项指标 + 重复组逐条路径 + 空文件夹 + 第 4 层以上深层样本；重复合并可选保留最早收藏 / 最近使用；
- 死链不在本地假装检查：可选只查前 10/25/50 条，交给 Agent 的 `check_urls_bulk` 分批真实请求；
- 一键「生成修复计划」：按风险从低到高，逐次确认后执行；
- 整理记录按天分组、日期头吸顶；失败重试 / 单条撤销 / 导出；
- 撤销中心：最近 10 步、每步摘要、不可撤销原因、撤销全部。

## 八、液态玻璃浮层

- 对话框与命令面板在 Chromium 下用 SVG 位移滤镜做边缘折射（`backdrop-filter: url(#…)`）：只有 6–7px 边带参与弯折，中央保持 72% 磨砂，11px 小字的 AA 不变；
- 边缘 1px「上亮下暗」描边 + 指针跟随高光 + 深浅两档颗粒；对话框把滚动移到内层，长内容滚动时高光边不跟着走；
- Firefox / Safari 走运行时特性检测，自动退回 `blur(8px)` 磨砂；Toast、菜单不参与折射（它们随滚动列表重采样，代价最高）；
- 位移图半分辨率生成（长边 ≤320px）并按尺寸缓存：面板打开一次约 1–3ms，静态时零成本；关闭即移除 filter 与临时 SVG 容器。

## 隐私

新增的「最近搜索」「命令面板最近使用」只存本地 `localStorage`，不上传、不参与模型请求；
关闭 / 清除即删除。死链检查只有你点「让 Agent 检查」才会真实请求链接。
