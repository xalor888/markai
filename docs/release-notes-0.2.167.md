# v0.2.167 — Agent 状态可见性与工具提优

这一版解决两件事：**模型明明在思考，界面却看不到**；以及**停着不动时不知道是在等还是卡死**。

## 一、思考过程丢失的根因

`client.ts` 的 `wrappedHandlers` 只转发了正文和工具调用，漏了 `onReasoning`。模型流出的 `reasoning_content` 在这一层被吞掉，UI 永远收不到思考块。

- 补上 `onReasoning` 转发；
- 新增回归测试：包装层必须转发思考，且首字/首思考到达时发出 `streaming` 状态。

## 二、Agent 阶段可见

新增 `chat:status` 事件与头部状态条：

- `连接模型 · 4s`
- `等待模型 · 31s · 仍在等待`
- `调用 批量移动 · 8s`
- `重试 2/5 · 3s`

配套：

- 超过 30 秒没有新输出，输入框上方出现提示条，带「停止」；
- 工具每 4 秒心跳一次，工具块显示已运行秒数；
- 重试不再往正文写「正在自动重试 N/5」，只更新状态条，正文保持干净；
- 重试退避上限 16s → 8s。

## 三、工具提优

- 每次工具调用加 180 秒**空闲超时**：有进度就续期，真卡住才中止并给出中文错误；
- `move_bookmarks` 每移动 1/5/全部上报进度；
- 完成记录带 `startedAt` / `durationMs`，UI 可显示耗时；
- 读类工具仍并行执行，写类串行避免竞争。

## 四、UI

- 头部只留头像/名称/状态点，阶段信息移到独立状态条（侧边栏不会再截成「连接模型…」）；
- 状态条常驻阶段、秒数、停止按钮；
- 工具卡 running 时显示实时秒数；
- 输入框忙时提示「Agent 正在处理，可点右侧停止…」。
