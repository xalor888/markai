# v0.2.172 — Agent 更快 · 工具更顺手 · 界面更敢点

这一版没有新概念，只做三件事：让 Agent 每轮少花 token、让工具一次做完一件事、让界面上“看得见”的东西都真的点得到。所有数字都来自仓库内的离线测量与真实 Chrome e2e，不靠体感。

## 一、Agent 效率：每轮固定开销降 32%

### 1. 工具定义从 5,765 → 3,502 token

36 个工具的定义仍是完整契约，但发给模型的是压缩版：

- 工具描述只保留“何时用、关键限制”，长解释移出请求；
- 参数名已在函数签名里，不再逐个重复同义描述；
- 只对真正影响行为的参数保留说明（`dryRun`、`beforeYear`、`keepOnly`、`checkReachable` 等安全参数一个不删）；
- 发送层去掉 `additionalProperties: false`（OpenAI 兼容接口非必填，zod 本来也会剥离未知键），约省 290 token/轮。

固定开销（系统提示 + 工具定义）从 **7,243 → 4,877 token**，降幅 **32.7%**；工具定义本身降 **39.2%**。

### 2. 搜索默认 50 条，且真的能翻页

`search_bookmarks` 过去默认把命中的全部书签倒进上下文，一次普通搜索就可能几万 token。现在：

- 默认 `limit=50`，返回 `nextOffset / hasMore / omitted`；
- 结果超过 55K 字符时按**完整条目**收缩，返回仍是合法 JSON，并明确提示用 `nextOffset` 继续；
- 不再出现“JSON 被拦腰截断，模型拿到半条记录”的情况。

`list_bookmarks` 同样按整条收缩，并给 `nextOffset`；`get_folder_content` 默认从 `depth=2 / limit=2000` 降为 `depth=1 / limit=100`——结构预览不再等于全量导出。

### 3. 历史里的工具结果变成“模型记得住的一句话”

旧实现把原始 JSON 截前 160 字符，而列表结果开头全是字段名，截完一个标题都没有。现在按结构转写：

```
50 条，next 50；1:Rust 异步 0 / 2:Rust 异步 1 / … 
```

模型跨轮追问“刚才那几条”时不必重查，少一次 5K token 级的往返。

### 4. 整理从 15 轮压到 3 轮（估算）

新增复合工具 `organize_folder`：一次调用完成“建分类 + 批量移动 + 暂存/直接落位”。按 6 个分类估算：

| 流程 | 轮数 | 估算 token |
| --- | --- | --- |
| 旧：stage + 每类 create + move + 收尾 | 15 | ~80,295 |
| 新：list + organize_folder + 收尾 | 3 | ~16,059 |

## 二、工具可用性：少让模型“撞墙重试”

- **`organize_folder` 真正可用**：补上 `staging` 参数（此前 handler 支持、schema 没暴露，模型传了会被静默剥离）；`plan` 里的书签数计入计划卡与授权上限；重复 id 在“是否为直接子项”之前就报“重复出现”；单条移动失败不再让整次整理变成“全没做”，返回值带 `failed / failures`，已成功的分类与移动如实保留。
- **`cleanup_sweep` 补上 `dryRun` schema**：安全参数不再是“文档里有、模型传不了”。
- **错误带下一步**：参数不合法、文件夹不存在、书签不存在、目标不是文件夹、循环嵌套、暂存已关闭等常见失败，统一追加可执行的下一步，而不是只回一句“错了”。
- **只读工具并行**：只读工具的分类仍只有 `turn-plan` 一份来源，避免并行集合与确认集合各说各话。

## 三、界面：把“看得见点不到”逐个消掉

### 侧边栏 Agent 抽屉

- 抽屉现在铺满侧栏宽度；此前沿用完整页的 `chatWidth`，会在右侧留一条 115px 的空白，内容贴左、空白区看得见却点不到；
- 头部新增显式的「关闭 Agent 面板」按钮，不再只能从 ⋯ 菜单里关；
- 未配置 AI 时，起手卡不再发一条必然被后台拒绝的消息，而是直接打开设置页。

### 书签列表与浮层

- 列表滚动区底部留出书签精灵的空间，最后一行不再被猫盖住；
- 紧凑侧栏里「整理」「移动」「删除」保留文字，不再只剩三个图标靠猜；
- 多选操作条在窄屏同样显示动作名；
- 整理记录列表不再被内层 `max-h-80` 腰斩，交给对话框统一滚动，长行能完整读到；
- 书签树浮层遮罩从 5% 提到 20%，明确“下面点不到”；收起按钮的命中区从 16px 提到 28px；
- 树浮层底部避让新手引导条，不再把“下一步”盖住。

### 弹窗

- 「收藏当前页面」移到首屏第一位置；不可收藏时直接写出原因（浏览器内部页面 / 扩展页 / 没有活动标签页），不再只靠一个灰按钮和 hover 提示；
- 未配置 AI 的提示与主操作不再互相抢注意力。

### 健康检查

- 原始英文 `aborted due to timeout` 改为中文“AI 请求超时”，并说明可稍后重试或换更快的模型/通道。
