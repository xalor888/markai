# MarkAI v0.2.23 发布说明

## 概述
v0.2.23 包含了关键配置缺陷修复、P4 分发就绪材料落地以及底层工具库的防御性加固：
1. **关键修复**：修复 `resolveConfig` 遗漏 `planMode` 字段导致后台聊天轮次无法激活计划模式的缺陷（T62）；
2. **P4 分发就绪**：编制完整的 Chrome Web Store 上架审核材料规范（`docs/store-listing.md`，包含 132 字符短描述、单一用途声明与逐项权限申诉）；
3. **视觉素材生成器**：编写纯 Node 的推广横幅生成器（`scripts/generate-promo-tiles.mjs`，基于原生 zlib 输出 440x280 与 1400x560 官方规格 PNG，测试自动校验）；
4. **拖拽下标安全**：增强 `src/lib/bookmark-dnd.ts` 的 `resolveDropIndex`，对负数与非整数下标安全钳位至 >= 0，杜绝非法下标向浏览器 API 传递；
5. **基础工具库加固**：
   - `src/lib/format.ts`：增加对异常远期时间戳的防御性日期格式化（避免误报为刚刚，T60）；
   - `src/lib/toast.ts`：完善通知去重、变体区分与队列硬容量上限（4条防 DOM 膨胀，T61）。

## 测试与反证体系
- 全量自动化测试：**430 项全绿**；
- 行为级反证（Falsification）：**125 条全绿**；
- 覆盖对上架材料、横幅尺寸、去重容量与计划模式映射的机器校验守卫。

## 升级建议与已知事项
- **无破坏性变更**：配置与操作历史完全向后兼容；
- **计划模式依然默认关闭**：是否开启仍由用户在设置面板自主决定；
- **真机自动化**：受限于环境容器中无法通过 `--load-extension` 启动扩展，真机全链路仍在本地手动验证阶段。
