# v0.2.32 — 品牌标恢复为原版

v0.2.31 的一次错误同步，本版修正。

## 错在哪

0.2.31 做「logo 统一」时，把 UI 里的品牌标识（`BrandMark`）从**用户一直在用、一眼能读懂的原版**换成了按工具栏 PNG 几何重绘的矢量版（Indigo 圆角卡片 + V 缺口白色书签）。

那一版的问题：**更难读懂**。工具栏 PNG 是扩展自身的图标（小尺寸下是"靛蓝方块+白色缺口"的抽象形状），拿它的几何当 UI 品牌标，等于用"最小的那个识别物"替换了"最清楚的那个识别物"。统一的目标应该是**向清楚的看齐**，而不是向抽象的看齐。

## 恢复

- `BrandMark` 回到原版：accent 圆角块 + lucide `BookMarked` 白色书签 + "Mark**AI**" 字标——即宣传片「归位」里拍到的页面左上角那一版，工作区顶栏 / popup / 聊天空态 / 设置页全部一致
- 0.2.31 新增的 `BrandIcon` 矢量组件**整个移除**，代码里留注释钉住「不要再用工具栏 PNG 几何重绘品牌标」
- **favicon 不受影响**：四个入口 HTML 的 `<link rel="icon">` 继续指向扩展真实图标 `/icon/32.png`——浏览器标签页该显示的是扩展真身，这不属于品牌标错误
