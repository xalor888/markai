# v0.2.33 — 插件图标统一为品牌标同款

继 0.2.32 恢复 UI 品牌标之后，把**工具栏图标**也换成了同一个设计。至此三处识别物完全一致：工具栏图标、UI 左上角品牌标、宣传片「归位」里的 logo。

## 旧图标的问题

旧版（脚本 v8）是「Indigo 卡片 + V 缺口白色缎带」几何：在 16px 工具栏尺寸下是一块"靛蓝方块 + 一点白"，读不出任何语义；而且与 UI 品牌标（accent 圆角块 + lucide `BookMarked` 书本字形）是**两套设计**——0.2.31 的错误同步正是这两套设计打架的结果。

## 新图标（脚本 v9）

与 `BrandMark` 同款：**Indigo `#4f46e5` 圆角方块 + 白色 lucide `BookMarked` 字形**（书本轮廓 + 燕尾书签）。

实现（`scripts/generate-icons.mjs` 仍是纯 Node 零依赖）：

- 字形按 lucide 原始路径（24 viewBox，stroke-width 2）等比放大 13 倍；两段圆弧用端点-圆心转换拉直成折线，全部线段以**胶囊 SDF** 描边（round cap/join 免费获得）
- 圆角半径对齐 UI `rounded-md` 比例（≈边长 21%），四周留 3% 抗锯齿安全边
- 超采样抗锯齿沿用原结构；16/32/48/96/128 全部重新生成，128px 约 1.3KB

无破坏性变更；功能与 0.2.32 完全一致，仅图标外观更换。已安装用户重载扩展后生效。
