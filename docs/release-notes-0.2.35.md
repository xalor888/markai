# v0.2.35 — 界面重做：顶栏从 11 个图标变成 3 个

这一版不加功能。它做的是一件事：**把你每天要看的那块屏幕重新排一遍。**

## 顶栏：11 个无文字图标 → 品牌标 · 一个搜索框 · ⋯

重做前顶栏摊着 11 个纯图标——收藏、待删、整理、时间线、全屏、侧边栏、聊天、快捷键、主题、设置……
全都没有文字，只能靠猜；真正的内容区被挤到只剩一行。

现在：

- **一个搜索框**（此前树里一个、列表里一个，各搜一半，永远搜不全）
- **一个 `⋯`**：待删清单、整理记录、Agent 面板、容器切换、快捷键、主题、设置全在里面
- 有待删项或整理失败时，`⋯` 上会点一个红点——**收起来不等于藏起来**

## 时间线不再是"另一个视图"

以前要切换"列表 / 时间线"两个按钮，切过去就丢了上下文。

现在它只是排序里的一项：**按收藏时间（全部书签）**——跨文件夹列出所有书签、按天分组、显示「共 N 条」。
顺带修了一个一直存在的坑：**排序下拉在侧边栏里根本没有**（代码里写着 `!compact`），
所以窄屏下你根本进不去时间线。

## 树默认收起，展开是浮层

410px 宽的侧边栏里，树常驻 176px，中栏只剩两百多——标题全被截断，一屏只有三行文件夹和一大片空白。

现在树收成 36px 的条，需要导航时展开成浮层**盖在列表上**，不挤压宽度。

## 每行只讲一件事

主行是标题，副行是域名；时间、路径、外链图标挪到 hover 才出现。此前五段信息挤在同一行，扫不动。

## ⌘K：一个框做三件事

搜书签、跳文件夹、执行动作（打开整理记录 / 待删清单 / 设置 / 切换主题……）。
↑↓ 选择、Enter 执行、Esc 关闭。找东西不用再先想"它在哪个文件夹"。

## 删掉：补整理

上一版的「补整理已有书签」按钮**整个移除**（消息协议、后台批量编排、进度条、剩余时间估算、取消，全部删除）。

原因不是它跑不起来，是它的形态错了：点一下按钮 → 后台拿一套固定算法 → 批量搬存量书签。
这和 MarkAI"对话驱动、每一步你看得见"是两套东西。给它加个预览只是套壳。

**它曾经把你的书签搬进 `其他书签/自动整理/<域名>` 七个文件夹，而且因为逐条写入把撤销点挤出保留上限，撤不回来。**

同时删掉的还有那层"按域名建文件夹"的兜底：

- 认不出归属时，**留在原地，一个字都不动**，并说明原因
- 系统提示里加了硬规则：**不要按域名新建文件夹**
- 理由是你原话——"那种按域名分类的，我从来都没有用过这种方法"。那种文件夹是程序硬造的，
  书签搬进去，你就再也认不出自己原来的收藏夹了

## 顺手修的

- 底部 200px 的"说明书"横幅 → 40px 单行，点「知道了」永不再现
- 列表行补了 `role="listitem"`、对话框补了 `data-testid`（可访问性与测试都更稳）

## 升级说明

- 已经是「自动整理」容器里的旧书签**不会**被自动删掉；不想留可以直接删。
- 撤销历史、整理记录、免打扰名单都保留，格式未变。

## 测试

- 单测 682 项（新增 14 条守卫：补整理已彻底移除、不建域名文件夹、命令面板打分、顶栏元素数）
- 真机 e2e 22 项 / 10.6s：默认 headless、全走 `data-testid`，只测"浏览器里点了有没有反应"
