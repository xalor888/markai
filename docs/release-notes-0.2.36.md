# v0.2.36 — 设置页重写 + 时间线按钮 + 自动整理可见开关

0.2.35 的重做漏了三件事，这一版补上。

## 设置页重写

重写前：单列 672px 的窄柱子、六个带边框的卡片竖着摞、整页 2300px。
每个字段「标签 / 输入框 / 说明」三段竖排，一屏只能看三四项，找一项要滚半天。

现在：

- **左侧固定导航**：AI 服务 / 上下文与预算 / Agent 行为 / 长期记忆 / 外观 / 数据管理，点一下直接跳
- **字段改成左右两栏**：标签在左（固定 148px）、控件在右，同样是"每项都看得清说明"，高度砍掉近一半
- **去掉卡片边框**：六个圆角框叠在一起时，边界比内容还抢眼；改成节标题 + 一条分隔线，靠留白分组
- 窄屏自动退回单列，不挤标签

顺带修掉一句失效文案：自动整理的说明里还写着"认不出时按域名归入「自动整理」"——
那层兜底在 0.2.35 已经删了。

## 时间线有了明确的按钮

0.2.35 把时间线做成了排序下拉里的一项。问题是：**"我怎么去时间线"这个动作不存在了**。

现在工具栏有一个带文字的按钮：**「时间线」**，点进去同一个位置变成 **「返回文件夹」**。
侧边栏（窄屏）下显示图标，完整页显示文字。

## 「自动整理」有了可见状态

它一直在后台跑（收藏一个页面 → 本地规则认人 → 认不出问 AI → 最后才留在原地），
但界面上**没有任何地方显示它在工作还是被关掉了**，所以会让人以为功能没了。

现在 `⋯` 菜单里有一项 **「收藏后自动整理 · 已开启 / 已关闭」**，点一下就能开关，
状态直接从存储读，不会显示成假的。

## 关于那个红色感叹号

三个独立探针（干净 profile、headless、加载构建产物）验证过：

- service worker 正常启动，零异常
- `page.html / sidepanel.html / popup.html / options.html` 四个页面零 404、零 console error
- zip 里 24 个文件与构建目录逐一对应，图标齐全，manifest 0.2.36 / MV3

也就是说**产物本身没有加载错误**。感叹号通常来自：旧版本残留（同一个扩展 ID 装了两份）、
或解压目录被移动/改动过。彻底重装一次即可：

1. `chrome://extensions` → 删掉 MarkAI
2. 重新解压 zip → 「加载已解压的扩展程序」
3. 如果还有感叹号，点该扩展卡片上的 **「错误」** 按钮，把里面的文本发我
