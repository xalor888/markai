# v0.2.45 — 底部提示条不再被 toast 盖住

## 问题

新手引导条常驻在窗口最底部（`整理记录在这里 1/3 · 下一步 · ✕`）。
而通知 toast 是 `fixed bottom-4` 的居中浮层。

两者必然撞上。实测（430px 侧边栏）：

```
引导条  top = 717  高 = 40
toast   底边 = 741
重叠 = 24px  ← 正好盖住那行引导文字
```

## 修法

引导条把自己 40px 的高度写进一个 CSS 变量 `--markai-bottom-bar`，
toast 的位置改成：

```css
bottom: calc(1rem + var(--markai-bottom-bar, 0px));
```

没有引导条时变量不存在，toast 仍然贴底 16px，行为不变。
卸载引导条时变量会被移除，不留残留。

修复后实测：`toast 底边 701`，`引导条 top 717` —— 不再重叠。

## 顺带修掉一张假截图

视觉审查脚本里 `09-sidepanel-collapsed` 和 `04-sidepanel` 是**同一张图**
（sha256 完全相同）。原因：紧凑模式下书签树**本来就是收起的**，
脚本去点「收起」自然毫无变化——方向搞反了。

现在改成拍**展开态**（430px 里 208px 的树覆盖层），
并且加了断言：树没真的出现就抛错，不产出错误截图。
文件也改名成 `09-sidepanel-tree-open.png`，名实一致。
