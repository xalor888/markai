# v0.2.51 — 上一版的安全修复留了个哑口

## 问题

0.2.48 修了「重新生成会把已执行的写操作再做一遍」——有写操作时不再给重试按钮。

但它漏了一半：**那段解释文字只在「一个块都没有」时才显示**。

而 Agent 只要调用过工具，消息里就有工具卡片（块数不为 0），于是：

```
工具卡片：create_bookmark ✓
（没有任何文字，没有重试按钮，也没有解释）
```

你看到的是几个工具卡片之后**突然没有下文**。既不知道发生了什么，
也没有任何可以点的下一步。

## 为什么之前没发现

修 0.2.48 时只用单测验证了「判断函数对不对」，没验证「那句话在真实界面里会不会出现」。
这一轮用假 AI 服务把这条路径在浏览器里跑了一遍，才暴露出来。

**判断逻辑对 ≠ 那段文字真的会显示。**

## 修法

判据从「有没有块」改成「有没有**文字**」：

```ts
const hasText = blocks.some(b => b.kind === 'text' && b.text.trim().length > 0);
```

空白文字（只有换行）不算回复。现在工具卡片之后会正常显示：

> （Agent 没有写回复，但这一轮已经执行了 1 个改动。需要继续请直接说下一句；要退回可点「撤销」。）

## 顺带补的两条 e2e

**上游 500**：验证界面给出「正在自动重试 N/5」的进度。
我第一版断言写的是「应该立刻出现 ⚠」，跑出来才发现——**500 是设计好的自动重试**，
一口气退避 5 次。是我的测试错了，不是产品错了。改成断言重试进度。

**401（不可重试）**：立刻给出可见错误，并且不会卡在「正在回复」。

实测输出：

```
⚠ API Key 无效或未授权（401）。 Invalid API key
```
