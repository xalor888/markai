# v0.2.58 — 「联系不上后台」和「你还没收藏过」同时出现在屏幕上

## 问题

整理记录面板在 `organize:list` 失败时，会同时显示两句话：

> ⚠ 无法联系后台进程，请再试一次。
>
> 还没有整理记录
> 收藏一个网页后，MarkAI 会自动把它归到合适的文件夹，记录会出现在这里。

一句话说"联系不上后台"，下一句说"你还没收藏过"——**自相矛盾**。

用户的真实情况是第三种：**既不是联系不上，也不是没有记录，而是这次没读到。**

而且那句"请再试一次"是纯文字，**没有按钮**。得自己去找上面的「刷新」。

## 修法

读失败时不再落到"没有记录"的空态，而是独占一块失败态：

> 读不到整理记录
> 这不代表你没有记录，只是这次没读到。点上面的「重试」，或稍后再打开。

并且把**重试**按钮直接放在提示条右侧，不用再找。

## 这是同一类问题的第三次

| 版本 | 场景 | 表现 |
|---|---|---|
| 0.2.55 | 弹窗待办卡片 | 还没读到就说"没有待确认的删除提议" |
| 0.2.57 | 撤销历史面板 | 读取失败时面板打不开、也没重试 |
| 0.2.58 | 整理记录面板 | 失败提示和"没有记录"同时出现 |

**共同点：把"不知道"渲染成了"没有"。**

这在界面上看起来最无害——用户不会觉得哪里坏了，只会得到一个错误的结论。

## 验证

e2e 三条（用 `Page.addScriptToEvaluateOnNewDocument` 把 `organize:list` 打坏）：

- 读失败时说清"联系不上后台"
- 读失败时**不再**同时说「还没有整理记录」
- 读失败时给出可点的「重试」

**证伪两次分别验**：

- 关掉失败态分支 → 「不再自相矛盾」转红
- 只去掉重试按钮 → 「给出可点的重试」转红
