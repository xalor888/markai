# v0.2.71 — 命令面板的键盘路径终于被测了

## 做了什么

面板占位符写着「搜书签、文件夹，或执行动作…」。但以前只验证过
**Ctrl+K 能打开**——它到底能不能搜到文件夹、搜不到时什么样、Esc 能不能关，
全都没测过。

补了四条：

1. Ctrl+K 能打开
2. **搜文件夹名能搜到「文件夹类型」的结果**
3. 搜不到时明确说「没有匹配…」，不是一片空白
4. Esc 能关掉

## 这一轮我写废了两版断言

### 第一版：拿文字当判据

```js
t.includes('文件夹') && t.includes('设计资料')   // ❌
```

动作里有一条叫「整理此文件夹」——**「文件夹」三个字恒成立**。

于是我把文件夹从数据源里整个删掉，证伪时它**照样绿**。

改成给结果项加 `data-kind`，断言 `data-kind="folder"` 的条目数量 ≥ 1 且名字对得上。

### 第二版：依赖环境里恰好存在的名字

断言里写死了种子数据里的「设计资料」。

但那个文件夹在当前 e2e 环境里**根本不存在** → `folderCount: 0` → 假失败。

改成测试**自己创建一个唯一命名的文件夹**再搜，用完删掉。

两版合起来，这次证伪真的转红了：

```
FAIL  搜文件夹名能搜到**文件夹类型**的结果 · {"folderCount":0,"folderNames":[]}
```

## 顺带盘了两处

- 右键菜单里**没有**「收藏当前页」，所以 0.2.70 放宽的 `file://` 判据不存在第二条路径。
- `export_bookmarks` 只把清单**返回给模型分析**，不产生文件；工具描述也是这么写的（诚实）。
  但 UI 里确实**没有「导出书签到文件」这个功能**——已记进待办池，不当作 bug。
