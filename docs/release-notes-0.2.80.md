# v0.2.80 — 空状态不许只说"空"

## 结论：大部分已经做好了，但没人守着

台账里「空状态都有下一步」这一项挂了很久。逐个看过之后：

| 空态 | 状态 |
|---|---|
| 列表：未选文件夹 | 「还没有选择文件夹」+ **查看书签栏** 按钮 |
| 列表：空文件夹 | 新建书签 / 新建文件夹 两个动作 |
| 列表：搜索无结果 | **清空搜索** + "换个词或清空后再看" |
| 列表：加载失败 | 错误原文 + **重试**（不把"出错"说成"没有内容"） |
| 时间线：整库为空 | "收藏任意页面后，它会按收藏时间出现在这里" |
| 时间线：过滤无匹配 | **清除过滤** |
| 撤销历史 | "Agent 每次整理都会在这里留下一步" |
| 长期记忆 | "直接对我说「记住：…」" |

**都已经有下一步了。** 但没有测试守着——下次有人改文案，很可能又退回成一句干巴巴的"空"。

## 做了什么

1. 给列表空态容器加 `data-testid="empty-state"`
2. e2e 一条：进到"搜索无结果"这个空态，断言里面**必须有动作**（「清空搜索」）

## 两处我自己写松的地方

### 第一处：正则被状态句本身满足

```
expectText = '没有匹配|清空搜索'
```

"没有匹配的书签" 这一句就够匹配了——**把下一步整个删掉，用例照样绿**。

收紧成只匹配动作：`'清空搜索'`。再证伪，立刻转红。

### 第二处：留了一个跑不到的用例

我本想连"未选文件夹"那条一起验，但页面没把 store 挂到 window，
从外部没法稳定切到那个状态。**那个用例是跑不到的**，直接删掉，
不为了凑数留一个永远绿的断言。
