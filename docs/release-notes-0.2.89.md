# v0.2.89 — 多窗口同步，第一次在浏览器里验

## 缺口

用户会同时开多个标签页（侧边栏 + 完整页，或两个完整页）。

在 A 里建的书签，**B 必须自己出现**——不能要求用户手动刷新。

这条以前**一次都没验过**：e2e 里所有段落都只开一个目标。

## 验了什么

同时开两个完整页，双向：

```
PASS  同步前：B 窗口里没有这条书签                        {"before":false}
PASS  在 A 里建的书签，B 窗口自动出现（不用手动刷新）      {"synced":true}
PASS  在 B 里删掉的书签，A 窗口也跟着消失                  {"goneInA":true}
```

创建和删除两个方向都通。

## 验证

**证伪**：去掉 `chrome.bookmarks.onCreated` 监听 → 我这条转红，
同时另外 6 条也被带红（中栏列表、时间线、命令面板、进入文件夹…）。

那 6 条被带红说明一件事：**这个监听是承载性的**，不是可选的装饰。
删掉它不止破坏多窗口同步，整个界面都不会随书签变化而更新了。
