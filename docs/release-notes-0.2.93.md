# v0.2.93 — 「新建书签」这条最基础的路，第一次走通

## 缺口

「新建书签」是最基础的一次写操作。

而 e2e **从没走过这个对话框**——`bookmark-dialogs.tsx` 里连一个 `data-testid`
都没有，全靠文案和 `#bookmark-title` / `#bookmark-url` 定位。

这条路径上任何一环接错（右键菜单不开、表单不提交、书签没落库），用户都直接卡住。

## 走通了

六步全链，每步都是可观测的状态：

```
PASS  右键树文件夹出现「新建书签」菜单项          {"opened":true,"menuHasNew":true}
PASS  点「新建书签」后弹出表单                    {"dlgOpen":true}
PASS  名称和地址两个框都能填                     {"filled":true}
PASS  填满之后「确定」变成可点                    {"found":true,"disabled":false}
PASS  提交之后书签真的建出来了（落到书签栏）      {"created":true}
PASS  新建的书签出现在界面上（不用手动刷新）      {"inList":true}
```

最后两条是关键：**不只是建出来了，界面上还看得见**（不用手动刷新）。

## 验证

**证伪**：让 `handleCreateBookmark` 直接返回 → 后两条立刻转红。
